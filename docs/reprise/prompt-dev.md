# Prompt de reprise : Dev

> À coller en premier message d'une nouvelle conversation Claude Code ouverte à la racine du dépôt Viewly.

```text
Je reprends la conversation Dev du projet Viewly sur un autre ordinateur.

1. Lis `CLAUDE.md` (façon de travailler, règles du produit, garde-fous), puis `docs/contexte/dev.md`.
2. Fais `git pull`, vérifie que `npm install` est à jour, et que Chromium est installé (`npx playwright install chromium` si besoin).
3. Lis la fin du `CHANGELOG.md` (dernières entrées) pour connaître l'état exact.
4. Reste dans le thème Dev : ne touche pas aux autres thèmes.
5. Résume-moi en 5 lignes maximum où on en est et quelle est la prochaine étape, puis attends mon accord avant de faire quoi que ce soit.
```
